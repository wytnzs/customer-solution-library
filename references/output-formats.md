# 客户解决方案库输出格式

## 1. 客户速览

```markdown
# 客户速览：<display_name>

## 一句话画像

## 当前状态

- 客户编号：
- 客户类型：
- 业务线：
- 阶段：
- 信息完整度：
- 最近更新：

## 已知事实

## 初步判断

## 待补充信息

## 下一步动作
```

## 2. 客户分析 Brief

```markdown
# 客户分析 Brief：<display_name>

## 结论先行

## 事实层

## 推断层

## 待确认层

## 核心问题

## 风险/机会排序

## 推荐解决顺序

## 不建议事项

## 下一步最小动作
```

## 3. 保险客户分析

```markdown
# 保险客户分析：<display_name>

## 当前结论

## 家庭责任

## 已有保障

## 保障缺口

## 健康/核保关注点

## 预算与缴费压力

## 风险优先级

## 建议补充资料

## 下一步沟通建议
```

## 4. 专属解决方案

```markdown
# 专属解决方案：<display_name>

## 方案边界

## 客户当前情况

## 核心问题

## 解决目标

## 分阶段建议

### 第一阶段：必须先解决

### 第二阶段：条件成熟后解决

### 第三阶段：长期优化

## 暂不建议事项

## 需要客户确认的信息

## 跟进计划
```

## 5. 客户可读版话术

```markdown
我先基于你目前提供的信息，帮你做一个初步梳理。

目前最需要先确认的是：

1. ...
2. ...
3. ...

从现有情况看，我建议先不要急着直接选产品/定方案，而是先把几个关键信息补齐：

- ...
- ...

等这些信息确认后，我再帮你把方案拆成“必须先做”和“后续优化”两部分，这样会更稳。
```

## 6. 跟进建议

```markdown
# 跟进建议：<display_name>

## 当前卡点

## 建议下一步

## 建议沟通方式

## 可发送话术

## 跟进时间

## 如果客户无回应
```

## 7. 信息缺口清单

```markdown
# 信息缺口清单：<display_name>

| 信息项 | 当前状态 | 为什么需要 | 获取方式 | 优先级 |
|---|---|---|---|---|
```

## 8. 候选客户列表

```markdown
找到多个可能客户：

| 序号 | customer_id | 显示名 | 类型 | 业务线 | 最近更新 | 路径 |
|---|---|---|---|---|---|---|

请确认要查看哪一个。
```

```markdown

## 本周优先跟进

## 缺少下一步动作

## 信息不足但仍活跃

## 可进入深度分析/方案复核
```
